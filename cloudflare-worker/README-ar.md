# ربط FLUX.1-schnell عبر Cloudflare Workers AI

هذا Worker يجعل الموقع يطلب صورة من نموذج FLUX المستضاف في Cloudflare، ويرسل الصورة للموقع مباشرة. لا تضع API Token أو Account ID في `index.html` أو `app.js`.

## النشر

1. أنشئ حساب Cloudflare مجانيًا وفعّل Workers AI من لوحة التحكم.
2. ثبّت أداة Wrangler على جهازك، وسجّل الدخول بحساب Cloudflare.
3. افتح الطرفية داخل هذا المجلد ثم نفّذ `npx wrangler deploy`.
4. انسخ رابط `workers.dev` الذي يظهر بعد النشر.
5. افتح الموقع ← خزنة المفاتيح والإعدادات، والصق الرابط في خانة Cloudflare Worker، ثم احفظ.
6. في إعدادات Worker على Cloudflare، عيّن المتغير `ALLOWED_ORIGIN` إلى أصل موقعك بدقة، مثل `https://example.com` (بلا مسار أو `/` أخير)، ثم أعد النشر.

## ملاحظات

- الموديل ثابت داخل Worker ولا يمكن للمتصفح إرسال اسم موديل آخر.
- الطلب الواحد يولد صورة واحدة بأربع خطوات؛ لا يُستخدم التوليد الجماعي في هذا المسار.
- الأبعاد المطابقة لمقاسات واجهة الموقع (720 أو 1024 أو 1280 بكسل لكل ضلع) هي المسموحة.
- الاستخدام يعتمد على الحصة المجانية اليومية لحساب Cloudflare. عند نفادها سيظهر تنبيه ويُرفض الطلب حتى التجديد.
- `ALLOWED_ORIGIN` يحدّ من استخدام المتصفحات من نطاقات أخرى، لكنه ليس نظام تسجيل دخول. راقب الاستهلاك من لوحة Cloudflare، ولا تفعّل خطة مدفوعة إن كنت لا تريد رسومًا.
