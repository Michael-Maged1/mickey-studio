سياسة الخصوصية وحماية البيانات (Privacy Policy)

آخر تحديث: أكتوبر 2026

1. مبدأ الخصوصية بالتصميم (Privacy by Design)

نحن نؤمن بأن إبداعك ملك لك وحدك. صُممت منصة Mickey Studio وفق معيار الخصوصية أولاً، بحيث تُعالج وتُخزن كافة أعمالك وتصاميمك محلياً داخل متصفحك أو جهازك دون مشاركتها أو بيعها لأي أطراف ثالثة.

2. التخزين المحلي المشفر (Local Encrypted Storage)

عند حفظ الصور، الفيديوهات، الملفات الصوتية، أو مفاتيح API الخاصة بك:

  • تُحفظ البيانات داخل قاعدة بيانات متصفحك المحلية (IndexedDB).
  • تُشفر المفاتيح الحساسة محلياً باستخدام خوارزمية التشفير القياسية AES-GCM 256-bit.
  • لا يتم رفع ملفاتك أو وسائطك إلى أي خادم تخزين مركزي تابع لنا ما لم تختر بنفسك مزامنة مشهد مع بريمير برو.

3. معالجة الوسائط عبر الأطراف الثالثة (Third-Party Processing)

لتوفير ميزات الذكاء الاصطناعي المتقدمة (توليد الصور، تفريغ الصوت، تحسين المطالبات)، يتم إرسال طلبات محددة ومؤقتة إلى مزودي الذكاء الاصطناعي الخارجيين:

  • توليد الصور: تُرسل المطالبة النصية والأبعاد المختارة عبر واجهة مؤقتة لتوليد الصورة وإرجاعها مباشرة لمتصفحك دون تخزين دائم على الخوادم.
  • التعليق الصوتي والتفريغ: تُرسل النصوص أو المقاطع الصوتية لمعالجتها فورياً، ولا تُستخدم بياناتك لتدريب النماذج العامة.
  • الربط مع بريمير: يتم تبادل كود المشهد JSON عبر قناة مشفرة ومؤقتة بصلاحية تنتهي تلقائياً خلال 24 ساعة.

4. رصد الأخطاء البرمجية المجهول (Zero-Data Error Telemetry)

لضمان استقرار المنصة وإصلاح الأعطال البرمجية، قد يرسل المتصفح تقريراً تقنياً مجهول الهوية عند حدوث خطأ برمجي غير متوقع. يتضمن التقرير فقط: نوع الخطأ، رقم السطر في الملف، وإصدار المتصفح. يُمنع بشكل صارم تضمين أي أسماء، نصوص مطالبات، مفاتيح، أو بيانات شخصية في تقارير الأخطاء.

5. التحكم في بياناتك وحذفها

لديك السيطرة المطلقة على بياناتك في أي وقت: يمكنك مسح خزنك بالكامل، حذف عناصر محددة، أو تصدير نسخة احتياطية محلية بصيغة JSON بضغطة زر واحدة من تبويب "معرض أعمالي".
